# ใบรับทราบความผิดพลาดในการทำงาน (Work Error Acknowledgement Form)

ฟอร์มออนไลน์หน้าเดียวสำหรับบันทึกความผิดพลาดในการจัด–เช็ค–แพ็คสินค้า ของทีมคลังสินค้า
กรอกข้อมูล ใส่รูป และเซ็นชื่อได้ในหน้าเว็บ แล้วสั่งพิมพ์ลงกระดาษ A4 ได้พอดี 1 หน้า

## เปิดใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (แนะนำ Chrome หรือ Edge) — ใช้ได้ทันทีโดยไม่ต้องติดตั้งอะไร
และไม่ต้องต่ออินเทอร์เน็ตก็ทำงานได้ (แค่ฟอนต์จะเปลี่ยนเป็นฟอนต์ในเครื่อง)

ถ้าเปิด GitHub Pages ไว้ จะเปิดใช้จากลิงก์ได้เลย:
`https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## สิ่งที่ทำได้

| ความสามารถ | วิธีใช้ |
|---|---|
| กรอกข้อความ | พิมพ์ได้ทุกช่อง ช่องข้อความยาวจะยืดตามที่พิมพ์ |
| เลขที่เอกสาร + วันที่บันทึก | รันอัตโนมัติเมื่อเปิดฟอร์มใหม่ (รูปแบบ `ERR-ปีเดือน-ลำดับ` เช่น `ERR-6908-001`) พิมพ์ทับได้ |
| วันที่สั่งซื้อ | กดที่ช่องแล้วเลือกจากปฏิทิน แสดงผลเป็น วว/ดด/ปี พ.ศ. |
| ติ๊กตัวเลือก | กดที่ป้ายได้ทั้งอัน |
| ใส่รูป 3 รูป | กดที่กรอบเพื่อเลือกไฟล์ / ลากไฟล์มาวาง / กด `Ctrl+V` วางสกรีนช็อต |
| จัดการรูป | ปุ่ม **หมุน** สำหรับรูปที่ถ่ายมาตะแคง และปุ่ม **ลบ** |
| เซ็นชื่อ | วาดลายเซ็นด้วยเมาส์หรือนิ้วในกรอบลายเซ็นทั้ง 4 ช่อง |
| บันทึกร่างอัตโนมัติ | ปิดหน้าเว็บแล้วเปิดใหม่ ข้อมูลยังอยู่ (เก็บในเครื่องผู้ใช้เท่านั้น) |
| พิมพ์ / บันทึก PDF | ปุ่มมุมขวาบน หรือกด `Ctrl+P` |

ระบบจะย่อกรอบรูปให้อัตโนมัติเมื่อข้อความยาวขึ้น เพื่อให้เอกสารอยู่ใน A4 หน้าเดียวเสมอ

## ตั้งค่าตอนสั่งพิมพ์

- ขนาดกระดาษ: **A4**
- ขอบกระดาษ (Margins): **Default**
- **ปิด** ตัวเลือก *Headers and footers*
- **เปิด** ตัวเลือก *Background graphics* (ถ้ามี) เพื่อให้เส้นกรอบและช่องติ๊กออกมาครบ

## หัวข้อในฟอร์ม

1. ข้อมูลคำสั่งซื้อ — แพลตฟอร์ม (Shopee / Lazada / Line / อื่น ๆ), หมายเลขคำสั่งซื้อ, ชื่อลูกค้า, วันที่สั่งซื้อ
2. ประเภทความผิดพลาด — เลือกได้มากกว่า 1 ข้อ
3. ข้อความที่ลูกค้าแจ้งเข้ามา
4. รูปภาพประกอบ — รูปที่ลูกค้าแจ้ง / ภาพจากวิดีโอแพ็คสินค้า / รูปคำสั่งซื้อ
5. สาเหตุ และแนวทางแก้ไข / ป้องกัน
6. ลงนามรับทราบ — คนจัดสินค้า, คนเช็คสินค้า, คนแพ็คสินค้า, หัวหน้างาน (ตั้งชื่อ นายไกรวิวัฒน์ เปล่งวิทยา ไว้ล่วงหน้า)

## ความเป็นส่วนตัว

ทุกอย่างทำงานในเบราว์เซอร์ของผู้ใช้เท่านั้น ไม่มีการส่งข้อมูล รูปภาพ หรือลายเซ็นออกไปที่เซิร์ฟเวอร์ใด ๆ
ร่างที่บันทึกอัตโนมัติและเลขรันเอกสารถูกเก็บไว้ใน `localStorage` ของเครื่องนั้นเครื่องเดียว — หากใช้หลายเครื่อง เลขรันจะนับแยกกัน

## เปิด GitHub Pages ให้คนอื่นใช้ได้

1. เข้าหน้า repo → **Settings** → **Pages**
2. Source เลือก **Deploy from a branch**
3. Branch เลือก **main** และโฟลเดอร์ **/ (root)** → **Save**
4. รอประมาณ 1 นาที แล้วเปิดลิงก์ที่ GitHub แสดงให้ — ส่งลิงก์นั้นให้ทีมใช้ได้เลย
